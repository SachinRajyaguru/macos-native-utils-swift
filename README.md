# macos-native-utils-swift
Swift-powered macOS utilities for system inspection, automation, diagnostics, and developer workflows.

## Installation

### Quick Install (One Command)
```bash
git clone https://github.com/SachinRajyaguru/macos-native-utils-swift.git && cd macos-native-utils-swift && ./Scripts/install.sh
```

### Manual Install
```bash
# Clone the repository
git clone https://github.com/SachinRajyaguru/macos-native-utils-swift.git
cd macos-native-utils-swift

# Run the installation script
./Scripts/install.sh
```

### What the Installation Does
- ✅ Clones the repository
- ✅ Compiles the Swift package in release mode
- ✅ Installs the `macapps` binary to `/usr/local/bin/`
- ✅ Makes it globally accessible from terminal

### Usage
Once installed, you can run from anywhere:
```bash
macapps
```

## Requirements
- macOS 10.15 or later
- Swift 5.5 or later
- Xcode Command Line Tools
